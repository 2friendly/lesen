# Future phoneme recordings

Audio is intentionally not bundled yet. When recordings are ready, place them in this directory using lowercase grapheme names, for example:

- `m.mp3`
- `s.mp3`
- `a-short.mp3`
- `t.mp3`
- `ee.mp3`
- `sh.mp3`

Record continuous sounds cleanly enough to sustain, and record stop sounds once without adding a trailing “uh”. Keep recording distance, loudness, file format, and silence padding consistent across the set. The playback manifest can then map each authored sound group to the appropriate file.
